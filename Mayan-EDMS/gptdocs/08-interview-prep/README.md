# Interview preparation

A typical mid-level loop includes recruiter/screen, technical deep dive, practical coding or debugging, system design, and behavioral interviews. Use this repository as evidence, not as a script. The golden rule: answer with a concrete example, tradeoff, and failure mode—not a definition. Never claim you authored Mayan code; say “while studying Mayan, I traced…” unless you actually contributed.

Answer shape: clarify → principle → anchored example → tradeoff/failure → test/measurement. At least 60% of this bank points to repository code. Start with the [two-week plan](07-two-week-cram-plan.md).
