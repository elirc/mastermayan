# Learning rubrics

| Skill | Junior observable | Mid observable | Senior observable | Interview-ready evidence |
| --- | --- | --- | --- | --- |
| Navigate | finds file by symbol | traces vertical slice | maps ownership/coupling | 3-minute repo map without notes |
| Contracts | names fields/status | protects backward compatibility | versions/migrates contracts | example + tradeoff + failure |
| Authorization | checks login | tests action/object/list scope | audits all paths/cache/inheritance | explains IDOR with wrong-parent test |
| Async | enqueues task | handles retry/idempotency/status | designs backpressure/reconciliation | narrates 202 and terminal failure |
| Data | edits model/migration | expand/backfill/contract | plans locks, dual compatibility, rollback | whiteboards safe schema change |
| Testing | happy path | negative/failure/side effects | test architecture and flake control | proposes cheapest regression proof |
| Debugging | reads logs | splits boundary/hypothesis | adds signals and prevention | scores 3/4 on timed round |
| Performance | says “cache” | measures query/latency | capacity/cost/fairness/rollback | baseline and p95 before solution |
| Review | finds style | prioritizes correctness/fit | reduces blast radius kindly | blocking/important/optional comments |
| Design | lists components | states invariants/tradeoffs | migration/security/ops/simpler option | 35-minute design with follow-ups |

Self-assessment: attach an anchor, test/output, and spoken answer to every checked skill. Confidence without evidence does not count.
