# Codebase cartography

Goal: turn “a huge Django repo” into navigable ownership boundaries. Complete the [system map](01-system-map.md), follow the [reading order](02-file-reading-order.md), learn the [domain language](03-domain-glossary.md), map [runtime/tooling](04-runtime-and-tooling-map.md), then trace [key flows](05-key-flows.md).

Exit check: from an HTTP symptom, name the likely URL/view, serializer/form, model/service, task, permission, and test locations before searching.
