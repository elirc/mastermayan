# Learning Rubrics

## Junior

- Can run or accurately describe the main local commands.
- Can name the major apps and their responsibilities.
- Can trace one feature from request to model to task.
- Can add a safe, existing-pattern test.

## Mid-level

- Can modify a cross-layer flow without breaking authorization.
- Can explain where validation and side effects happen.
- Can write useful regression tests for async or permission behavior.
- Can leave high-signal review comments about correctness and maintainability.

## Senior

- Can critique architectural tradeoffs without demanding a rewrite.
- Can propose a migration path with rollback and test strategy.
- Can reason about observability, idempotency, and blast radius.
- Can teach the codebase’s patterns to others clearly.
