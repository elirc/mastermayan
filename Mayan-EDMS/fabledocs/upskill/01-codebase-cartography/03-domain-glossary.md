# Domain glossary

The vocabulary of this codebase, with code locations. The first four entries are the ones juniors mix up in week one — and the ones an interviewer will probe if you claim you know the repo.

| Term | Meaning here | Code home | Trap |
| --- | --- | --- | --- |
| **Document** | The logical business object: label, type, language, UUID. Owns files and versions. | [document_models.py](../../../mayan/apps/documents/models/document_models.py#L41-L108) | A Document can exist with **no file at all** (`is_stub=True`, e.g. deferred API upload) |
| **DocumentFile** | One immutable uploaded binary: checksum, MIME type, size, storage path. A document accumulates many. | [document_file_models.py](../../../mayan/apps/documents/models/document_file_models.py#L51-L129) | "New upload" never replaces bytes; it appends a new DocumentFile |
| **DocumentVersion** | A *presentation*: an ordered mapping of pages drawn from any of the document's files. Exactly one is `active`. | [document_version_models.py](../../../mayan/apps/documents/models/document_version_models.py#L45-L72), remap at [L315–L338](../../../mayan/apps/documents/models/document_version_models.py#L315-L338) | Versions don't store bytes. Deleting/reordering pages edits the mapping, not the file |
| **Page** (file vs version) | `DocumentFilePage` = physical page of a binary. `DocumentVersionPage` = pointer (GenericFK) to a content object, usually a file page. | [document_file_page_models.py](../../../mayan/apps/documents/models/document_file_page_models.py) | OCR content hangs off **version** pages; parsing content off **file** pages |
| **DocumentType** | Category + policy bundle: retention periods, quick labels, which workflows and metadata apply. | [document_type_models.py](../../../mayan/apps/documents/models/document_type_models.py) | Changing a document's type re-evaluates policies — it's a business action, not a rename ([document_models.py](../../../mayan/apps/documents/models/document_models.py#L165-L183)) |
| **Trash / TrashedDocument** | Soft-delete state. `delete()` first flips `in_trash`; only a second delete destroys rows and storage files. | [document_models.py](../../../mayan/apps/documents/models/document_models.py#L142-L163) | `Document.objects` still sees trashed docs; use `Document.valid` |
| **Stub** | DB row for a document whose file hasn't arrived yet. Reaped periodically. | [document_models.py](../../../mayan/apps/documents/models/document_models.py#L98-L104), reaper task [documents/tasks.py](../../../mayan/apps/documents/tasks.py#L129-L137) | |
| **Permission / StoredPermission** | A named capability (`documents.document_view`). In-memory class + DB twin created on demand. | [permissions/classes.py](../../../mayan/apps/permissions/classes.py#L49-L129) | Permissions are *labels*; they grant nothing until attached to a Role or ACL |
| **Role** | Grants permissions. Users get roles **only through group membership** — never directly. | [permissions/models.py](../../../mayan/apps/permissions/models.py#L193-L216) | The chain is user → group → role → permission; forget a link and access silently fails |
| **ACL (AccessControlList)** | Per-object grant: (content_type, object_id, role) → permissions. The object-level layer on top of roles. | [acls/managers.py](../../../mayan/apps/acls/managers.py#L26-L30) | ACLs also *inherit*: access to a DocumentType flows down to its Documents (see [03-architecture/03](../03-architecture-and-patterns/03-validation-auth-and-permissions.md)) |
| **Event** | Audit-trail entry (django-activity-stream action) with a dotted ID like `documents.document_created`. Committed by model methods via `@method_event`. | [events/classes.py](../../../mayan/apps/events/classes.py#L323-L446) | `_event_actor` is smuggled through instance `__dict__`, not an argument — grep for it before renaming anything |
| **Source** | An ingestion channel (web form, staging folder, watch folder, IMAP/POP3 email, SANE scanner), configured as a DB row + plugin backend class. | [sources/source_backends/](../../../mayan/apps/sources/source_backends/) | The watch folder **deletes** files it ingests ([watch_folder_backends.py](../../../mayan/apps/sources/source_backends/watch_folder_backends.py#L100-L112)) |
| **SharedUploadedFile** | Temporary staging row+blob that carries an upload from the web process to a Celery worker. | [storage/models.py](../../../mayan/apps/storage/models.py#L108-L131) | Workers receive its **ID**; cleanup on success *and* failure is the upload task's job ([documents/tasks.py](../../../mayan/apps/documents/tasks.py#L82-L124)) |
| **DownloadFile** | The reverse: a worker-produced artifact (e.g. PDF export) parked for the user to download, with its own permission. | [storage/models.py](../../../mayan/apps/storage/models.py#L34-L61) | |
| **Cache / CachePartition / CachePartitionFile** | Size-bounded storage for generated artifacts (page images, PDF intermediates), pruned LRU-ish by hits/datetime under distributed locks. | [file_caching/models.py](../../../mayan/apps/file_caching/models.py#L105-L152) | Purging a cache is safe (regenerable); deleting the *storage* is not |
| **Workflow / WorkflowInstance** | A state machine template attached to document types; an instance per document. Current state = destination of the **last log entry**. | [workflow_instance_models.py](../../../mayan/apps/document_states/models/workflow_instance_models.py#L132-L143) | There is no `state` column to UPDATE — appending a log entry *is* the transition |
| **Transition / State action** | Edge in the state machine; entry/exit actions run side effects (HTTP POST, sign, change type…) when a transition lands. | [workflow_instance_models.py](../../../mayan/apps/document_states/models/workflow_instance_models.py#L282-L311) | Actions run synchronously inside the log entry's `save()` |
| **Checkout** | Exclusive editing lease on a document; can block new file uploads via a registered hook. | [checkouts/models.py](../../../mayan/apps/checkouts/models.py#L28-L58), hook wiring [checkouts/apps.py](../../../mayan/apps/checkouts/apps.py#L66-L68) | |
| **Index (document_indexing)** | A user-defined tree that auto-files documents by evaluating templates (e.g. by year/month) — *not* the search index. | [document_indexing/](../../../mayan/apps/document_indexing/) | "Index" is the #1 overloaded word; `dynamic_search` owns the search index |
| **SearchModel** | Declaration of which fields of which model are searchable, registered per app. | [documents/search.py](../../../mayan/apps/documents/search.py#L22-L56) | Search results return **proxy models** (`DocumentSearchResult`) so ACL filtering and links still work |
| **Layer / Transformation** | Converter concept: ordered image operations (rotate, zoom, redaction) attached per page, composited at render time. | [converter/classes.py](../../../mayan/apps/converter/classes.py#L275-L430) | Redactions are just a high-priority layer — access to *unredacted* output is a distinct permission |
| **Quick label** | Predefined filename choices per document type. | [document_type_models.py](../../../mayan/apps/documents/models/document_type_models.py) | |
| **Smart settings** | The `MAYAN_*` env-var → settings bridge with per-app namespaces. | [smart_settings/](../../../mayan/apps/smart_settings/), consumed in [settings/base.py](../../../mayan/settings/base.py#L18-L28) | |

Near-synonyms to keep straight: **version vs file** (presentation vs bytes); **index vs search** (filing tree vs query engine); **permission vs ACL** (capability label vs per-object grant); **trash vs delete** (reversible flag vs destructive cascade); **Cache vs Django cache** (file artifact store vs key-value cache).

**Drill:** a user says "I uploaded a new version of my contract." Write the two sentences describing what actually happened in the data model (which rows were created, which weren't). *Basic:* new DocumentFile. *Solid:* new DocumentFile + page objects + (by default action) new version page mappings, checksum/MIME computed in `save()`. *Strong:* you also name the default `DocumentFileActionUseNewPages` selection in [document_models.py](../../../mayan/apps/documents/models/document_models.py#L195-L196) and what changes if the "append" action is chosen instead.
