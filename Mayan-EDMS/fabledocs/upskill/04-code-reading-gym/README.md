# 04 — Code reading gym

Reading code is a trainable skill with drills, not an osmosis process. Do these with a timer and write your answers down **before** checking — the pain of being wrong is the mechanism.

| File | Exercise type | Time per rep |
| --- | --- | --- |
| [01-annotation-drills.md](01-annotation-drills.md) | Annotate real excerpts: inputs, outputs, invariants, side effects, failure modes | 15 min |
| [02-trace-tables.md](02-trace-tables.md) | Follow a value through layers, step by step | 20 min |
| [03-fake-code-contrasts.md](03-fake-code-contrasts.md) | Bad instinct vs repo-grade shape, side by side | 10 min |
| [04-review-katas.md](04-review-katas.md) | Review fake PRs against this codebase's standards | 25 min |

Interview mapping: annotation ≈ "walk me through this code" screens; traces ≈ debugging rounds; katas ≈ code-review rounds. The timed versions live in [08/05](../08-interview-prep/05-debugging-and-code-review-rounds.md).
