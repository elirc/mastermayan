# 07 — Career and collaboration

The skills that get you promoted are not just technical. This module covers reviewing, writing, and communicating — using this repo's actual contribution norms.

| File | Focus |
| --- | --- |
| [01-code-review-mindset.md](01-code-review-mindset.md) | The five review layers + a repo checklist |
| [02-writing-prs-and-rfcs.md](02-writing-prs-and-rfcs.md) | PR/commit/RFC templates tuned to Mayan |
| [03-maintainer-communication.md](03-maintainer-communication.md) | Asking, disagreeing, reporting — without outsourcing your thinking |

This project's process is real and strict: a **Contributor Assignment Agreement** must be mailed/scanned, commits must be **DCO-signed** (`git commit -s`, [CONTRIBUTING.md](../../../CONTRIBUTING.md)), real names only, target-branch discipline (`master` stable, `development` unstable), and **every change needs a test**. Internalize that a maintainer's time is the scarcest resource — the whole module optimizes for spending it well.
