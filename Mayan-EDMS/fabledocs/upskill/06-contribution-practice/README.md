# 06 — Contribution practice

Reading builds recognition; contributing builds judgment. These tickets are sized and anchored so you can actually do them against this code (or, since this working copy has no upstream remote, do them as exercises and self-review with module 07).

Every ticket ends with **Interview story potential** — the STAR story completing it would produce ([08/06](../08-interview-prep/06-behavioral-star-stories.md)). Contribution realism rule (non-negotiable): each item answers *why it's useful, why the blast radius is small, what existing pattern it follows, how it's tested, and what would make a maintainer reject it.* A drive-by refactor with none of those is how you get your first PR closed.
